# NetSI PhD Bootcamp 2026, hackathon materials

Starter code and step-by-step guides for the two Thursday sessions (Sep 3, 2026):
**Networks on the Cluster** (10am to 12pm) and **Agentic Computing** (2pm to 4pm).

## Before you start
Read **[SETUP.md](SETUP.md)**: request Explorer access, set up SSH so `ssh explorer` works,
and log in to Claude. Do this *before* the session so we don't lose time.

## The hackathon
Everything you run lives under **[`hackathon/`](hackathon/)**. Start with
**[`hackathon/README.md`](hackathon/README.md)**, then pick a track.

- **Session 1 (cluster):** `hackathon/cluster/`, a first job (`00-hello`), a guided array
  walkthrough (`track-a-parallel-sim`), then pick Track A (parallel sims), B (GNN on GPU),
  or C (big-graph).
- **Session 2 (agentic):** `hackathon/agentic/`, build a dashboard, extend your Session 1 work,
  or recreate a paper, all by driving an agent.

Each track folder has a `README.md` (goal, steps, checklist) and starter code that runs on
Explorer as-is.
